# صيدلية سلامة (Salama Pharmacy) – منصة الصيدلية الإلكترونية المتكاملة بمصر

**صيدلية سلامة (Salama Pharmacy)** هي منصة صيدلية إلكترونية حديثة، متكاملة، وسريعة الاستجابة مبنية بأحدث تقنيات **React.js**، **Vite**، و**React Router DOM**، ومخصصة لخدمة السوق المصري وفق أعلى معايير الجودة المعتمدة من هيئة الدواء المصرية (EDA).

---

## 🌟 أبرز التحديثات والمميزات (Key Features)

### 1. الحفاظ الصارم على الهوية البصرية ونظام الألوان (Exact Color Palette)
- **Primary Green:** `#00B207` (اللون الأخضر الصيدلاني الأساسي للأزرار والروابط النشطة)
- **Dark Green:** `#008A05` (حالات التمرير والتأكيد)
- **Dark Text:** `#1A1A1A` (العناوين والنصوص الرئيسية)
- **Light Background:** `#F7F7F7` & `#FAFAFA` (خلفيات الأقسام والكروت)
- **Border Gray:** `#E6E6E6` (الفواصل وحدود البطاقات)
- **White:** `#FFFFFF` (أسطح البطاقات والحاويات)
- **Secondary Text:** `#666666` (التفاصيل والتقييمات والوصف)
- **Accent Soft Green:** `#EDFBEF` (شارات التوفير والوسوم)
- **الخطوط:** دمج خط **Cairo** المتميز باللغة العربية مع **Poppins** و**Inter**.

### 2. تنظيف الواجهة وإزالة الرموز الزائدة (Cleaned Icons & UI)
- إزالة علامات الجمع الزائدة `+` التي كانت تظهر بشكل غير لائق في نهاية الأرقام أو الشعارات.
- استبدال الشعار برمز دوائي صيدلاني أنيق ومعبر (`FaPrescriptionBottleAlt`).
- تنقية بطاقات المنتجات والأزرار من أي عناصر زائدة أو عشوائية لتوفير تجربة مستخدم نقية وتجارية حقيقية.

### 3. التصفية الديناميكية الفورية للأقسام (Dynamic Category Filtering)
- **شريط التنقل العلوي والقائمة (Top Navbar & Dropdown):** عند الضغط على أي قسم (علاج وأدوية، العناية بالبشرة، العناية بالجسم، فيتامينات ومكملات، الأم والطفل، إسعافات وأجهزة)، يتم تحديث شبكة المنتجات فورياً وتلقائياً لتعرض **فقط** الأدوية والمستحضرات التابعة للقسم المختار.
- **في الصفحة الرئيسية (Home Page):** أزرار تصفية سريعة تفاعلية (Pills) تمكن العميل من التبديل بين الأقسام مباشرة دون مغادرة الصفحة مع عرض فوري لمنتجات القسم المختار.
- **في صفحة المنتجات (Products Page):** شريط جانبي شامل يعرض عدد المنتجات لكل قسم، مع شريط نطاق أسعار بالجنيه المصري (من 20 إلى 1500 ج.م)، وفلتر التقييم وتوافر المخزون.

### 4. الهوية المصرية الكاملة (Egyptian Rebranding)
- الاسم المعتمد عبر كامل التطبيق: **صيدلية سلامة (Salama Pharmacy)**.
- تحديث جميع العناوين، الفوتر، الهيدر، النشرة الإخبارية، ورسائل الإشعارات.

### 5. التوطين المصري للعملة والبيانات (Egyptian Localization)
- **العملة:** استخدام الجنيه المصري بالكامل (**ج.م** / **EGP**).
- **المنتجات:** 32 منتجاً حقيقياً من الأدوية والمستحضرات الأكثر طلباً وشهرة في الصيدليات المصرية (بنادول إكسترا، كونجستال، كتافلام، أوجمنتين، أنتينال، أوتريفين، إيفا كولاجين، ستارفيل، سيباكلار، بوباي واقي شمس، بانثينول، بيزلين، بيتادين، سيجنال، ديتول، بانتين، ليسترين، سي-ريتارد، أوميجا 3 بلس، سانسوفيت، نيوروتون، فيتاماونت، سانوسان، سودوكريم، بيبانتين، حفاضات مولفيكس، حليب هيرو بيبي، أجهزة قياس الضغط بويرر الألماني، وجهاز السكر أكيوتشيك).
- **الأسعار:** أسعار واقعية بالجنيه المصري مطابقة للتسعيرة الدوائية بمصر.
- **الشحن المجاني:** توصيل مجاني تلقائي لجميع الطلبات بقيمة 350 ج.م أو أكثر (ورسوم 30 ج.م للطلبات الأقل).
- **الخط الساخن المصري:** `19888` وواتساب الطلبات `0100 555 1988`.
- **العناوين والفروع:** الدقي (45 شارع مصدق)، مدينة نصر (شارع عباس العقاد)، التجمع الخامس (ميديكال بارك)، والمعادي (شارع اللاسلكي).
- **طرق الدفع المصرية:** الدفع عند الاستلام (كاش)، إنستاباي (InstaPay)، فودافون كاش والمحافظ الإلكترونية، وبطاقات ميزة البنكية.

## 📁 هيكل الأقسام الطبية (Categories)

1. **Treatments (علاج وأدوية):** مسكنات، أدوية البرد، مضادات حيوية، ومطهرات معوية.
2. **Skin Care (العناية بالبشرة):** كريمات ترطيب، واقي شمس، وتفتيح البشرة ومكافحة التجاعيد.
3. **Body Care (العناية بالجسم والشعر):** غسول مطهر، معجون أسنان، وشامبو علاجي.
4. **Vitamins & Supplements (فيتامينات ومكملات):** فيتامين سي، أوميجا 3، كالسيوم، ومقويات الأعصاب.
5. **Mother & Baby (الأم والطفل):** شامبو أطفال خالي من الدموع، كريمات الحفاض، وحليب رضع.
6. **First Aid & Devices (إسعافات وأجهزة طبية):** أجهزة ضغط، أجهزة سكر، بلاستر طبي، ومطهرات جروح.

## 🚀 تشغيل المشروع محلياً (Running Locally)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev
```

التطبيق يعمل الآن على:
```
http://localhost:3000/
```

لبناء النسخة الإنتاجية النهائية:
```bash
npm run build
```
